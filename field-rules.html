One-Page Field Rules

The whole protocol on one page. Print it, tape it above the box. Human mesh, sneakernet, best effort—the rest is details.

  1. Write a postcard.
  2. Address it to a handle, scene, hackerspace, meetup, or conference.
  3. Hand it to someone going the right way.

Postcard fields

Use handles, not legal names.
Use approximate locations, not private addresses.

Couriers

  • Carry mail only if you want to.
  • Take only what you want to carry.
  • Move it closer if you can.
  • Drop it at a hackerspace, meetup, conference, or local hacker.
  • If you cannot deliver it, pass it on or boomerang it back.

Postmasters

  1. Collect mail.
  2. Sort mail.
  3. Send mail onward.

Suggested sorting:

LOCAL / NORTH / SOUTH / EAST / WEST / UNKNOWN

Unroutable? Send it up to a bigger post office. No sender field, so no return to sender.

Message rules

  • Postcards only.
  • No sealed envelopes.
  • No packages.
  • No secrets.
  • No doxxing.
  • No harassment.
  • No dangerous cargo.
  • No private info without consent.

Assume every postcard is public.

The protocol

Best effort. No guarantees. No obligation. Route closer. Keep it weird.
